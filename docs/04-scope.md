# Scope

Questo documento separa ciò che serve **al business** da ciò che serve **al software**, e definisce cosa entra nella prima versione (MVP).

## Business: cosa serve per il primo ospite

- [ ] Almeno 1–2 case pronte e in regola per l'affitto
- [ ] Almeno un pacchetto stagionale completo, con persone e produttori confermati
- [ ] Prezzo definito e sostenibile
- [ ] Forma legale e permessi chiariti (vedi [domande aperte](05-domande-aperte.md))
- [ ] Un modo per farsi trovare e farsi pagare

## Software: ipotesi di MVP

Obiettivo: **vendere i primi pacchetti** con il minimo sforzo tecnico.

| Funzione | MVP | Dopo |
| --- | --- | --- |
| Sito vetrina con pacchetti, foto, programma | Sì | |
| Italiano + inglese | Sì | Altre lingue (tedesco?) |
| Richiesta di prenotazione / contatto | Sì | |
| Calendario disponibilità per pacchetto e casa | Semplice | Gestione completa |
| Pagamento online (acconto o totale) | Da decidere | |
| Area admin per gestire case, esperienze, date | | Sì |
| Area ospite (programma, info pratiche) | | Sì |
| Gestione partner (produttori, guide) | | Sì |
| Blog / storie delle tradizioni (SEO) | | Sì |

## Fuori scope (per ora)

- App mobile nativa.
- Marketplace aperto a più territori.
- Pacchetti personalizzabili componendo singole esperienze.
