# Modifiche

Cartella per raccogliere le modifiche da fare al portale.

- Scrivi i punti in [`da-fare.md`](da-fare.md), uno per riga, come ti vengono: anche frasi brevi vanno bene.
- Se una modifica riguarda delle foto, mettile in [`foto/`](foto/) e citale nel punto (es. "usa `foto/raccolta.jpg` per l'autunno").
- Quando un punto è fatto lo spunto (`[x]`) e lo sposto in fondo, nella sezione "Fatte".
