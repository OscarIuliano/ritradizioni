# Riscopri Tradizioni

Soggiorni di 5 giorni in Calabria, tra Lamezia Terme e Pianopoli, per vivere le tradizioni del territorio insieme a chi le porta avanti: raccogliere le olive e portarsi a casa l'olio, fare la salsa di pomodoro d'estate, cucinare piatti locali, camminare in posti che i turisti di solito non vedono.

Gli ospiti alloggiano in case del paese oggi vuote, sul modello dell'albergo diffuso.
